# Chatlog context glossary

This repository is a local, governed memory compiler. Immutable redacted evidence is canonical; indexes, conversations, derived reports, and memory are replaceable projections.

| Term               | Meaning                                                        | Not this                                   |
| ------------------ | -------------------------------------------------------------- | ------------------------------------------ |
| Source observation | One provider-native item under a declared capture policy       | A derived fact                             |
| Agent event        | A normalized statement about observed activity                 | A transcript summary                       |
| Evidence           | Immutable events plus exact references and provenance          | A model conclusion                         |
| Insight            | A revisable claim derived from evidence or a human assertion   | Enforcement policy                         |
| Policy             | A rule that controls access, promotion, delivery, or authority | A learned preference                       |
| Context bundle     | A finite, policy-filtered selection for one task and target    | The archive                                |
| Intervention       | A context bundle that Chatlog delivered or exposed             | A retrieval candidate that was never shown |
| Outcome            | An observed result after an intervention                       | An agent statement that it succeeded       |
| Memory             | A product projection of active insights and evidence routes    | Canonical truth                            |

## Canonical evidence boundary

`SourceAdapter.adapt()` emits an immutable `EventBatch`. Events retain provider and harness provenance, source paths and positions, native identifiers, adapter recipe, capture-policy version, semantic loss, and typed relations. Conversations are deterministic compatibility projections generated by `src/conversation-projection.ts`; they are not an authority.

The corpus manifest is the authority for active source mappings. Each mapping records the canonical event-batch hash and conversation projection hash (with `contentHash` retained for legacy pointers). SQLite stores rebuildable event and conversation projections and must fail closed when its active receipt differs from the manifest.

Reasoning and opaque provider events remain evidence but are excluded from ordinary message full-text search, insight mining, handoffs, and context delivery. No provider payload is stored unredacted.
